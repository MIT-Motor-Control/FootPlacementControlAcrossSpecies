This folder contains the processing code for the fly dataset used in our study. This datasets was published alongide the following paper : 

"The manifold structure of limb coordination in walking Drosophila", DeAngelis, B and Zavatone-Veth, J A and Clark, D A, 2019, Elife, 8, e46409

# How to run the code 
Run the `scriptExtractionFly.m` to extract and preprocess the input dataset (directly downloade from the data repository). It will generate the processed data that can subsequently be processed by the file `script_io_fly.py` in the format directly used by the foot placement inference code.
