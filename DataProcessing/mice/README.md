This folder contains the code used to process the data for the mouse dataset. This dataset was published alongside the following paper 

"Deep phenotyping reveals movement phenotypes in mouse neurodevelopmental models", 2022, Klibaite, U and Kislin, M and Verpeut, J L and Bergeler, S and Sun, X and Shaevitz, J W and Wang, S S H, Molecular Autism, 13 (12)

The paper associated with the present code only focussed on the wild types cohorts, however the processing code is provided for the whole dataset (including the mutant groups).
